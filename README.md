# Electric Flow Portfolio

Quiero crear desde cero un PORTAFOLIO PERSONAL PROFESIONAL, MODERNO, MUY INTERACTIVO Y RESPONSIVO.

IMPORTANTE:

No quiero una página web estática ni un diseño genérico de portafolio.

Quiero una experiencia visual moderna, tecnológica, elegante y llamativa que transmita que soy un desarrollador de software.

El objetivo principal es que cuando una empresa o reclutador entre al portafolio, la página genere una primera impresión fuerte y profesional.

==================================================

1. TECNOLOGÍA

==================================================

Construye el proyecto utilizando:

- React

- TypeScript

- Vite

- CSS moderno

- Lucide React para iconos si son necesarios

No utilizar Bootstrap.

No utilizar Material UI.

No utilizar jQuery.

Mantener una arquitectura sencilla y fácil de modificar.

==================================================

2. OBJETIVO DEL DISEÑO

==================================================

El portafolio debe sentirse:

- Profesional

- Tecnológico

- Moderno

- Premium

- Interactivo

- Dinámico

- Elegante

- Minimalista pero llamativo

- Orientado a empresas y reclutadores

NO quiero:

- Diseño de plantilla genérica

- Demasiados colores

- Animaciones exageradas

- Elementos infantiles

- Diseño sobrecargado

- Gradientes excesivos

- Efectos que dificulten la lectura

La interacción debe sentirse intencional y profesional.

==================================================

4. EXPERIENCIA GENERAL

==================================================

Quiero que toda la página tenga sensación de movimiento.

Cuando el usuario haga scroll:

- Las secciones deben aparecer progresivamente.

- Los títulos deben aparecer con animación.

- Los textos deben aparecer después de los títulos.

- Los botones deben aparecer después del texto.

- Las tarjetas deben aparecer una por una.

- Las habilidades deben aparecer progresivamente.

- Los elementos deben entrar suavemente desde abajo.

- Utilizar pequeños efectos de escala y blur.

- Utilizar diferentes delays entre elementos.

NO hacer que todo aparezca al mismo tiempo.

Quiero una sensación similar a:

elemento 1

↓

elemento 2

↓

elemento 3

↓

elemento 4

Cada elemento debe tener una pequeña diferencia de tiempo.

Usar Intersection Observer o una solución equivalente para detectar cuándo los elementos entran en pantalla.

Las animaciones deben volver a ejecutarse cuando el elemento salga y vuelva a entrar en pantalla.

==================================================

5. EFECTOS DE TEXTO

==================================================

Las letras también deben tener animaciones.

Los títulos principales deben:

- aparecer con fade

- desplazarse ligeramente desde abajo

- comenzar con un pequeño blur

- terminar enfocados

- utilizar pequeños efectos de glow azul

El nombre "Daniel" debe tener:

color #0000FF

y un glow azul sutil.

No utilizar glow excesivo.

Al pasar el mouse sobre palabras importantes:

- aumentar ligeramente el brillo

- cambiar ligeramente el color

- agregar glow

Crear sensación de profundidad.

Las luces del fondo pueden moverse lentamente utilizando CSS.

No utilizar animaciones rápidas.

18. SCROLL REVEAL

==================================================

Crear un sistema reutilizable para animaciones.

Cada elemento puede tener:

reveal-up

reveal-left

reveal-right

reveal-scale

reveal-blur

Las animaciones deben utilizar:

opacity

transform

filter blur

Ejemplo conceptual:

Estado inicial:

opacity: 0

transform: translateY(50px)

filter: blur(8px)

Estado final:

opacity: 1

transform: translateY(0)

filter: blur(0)

Duración aproximada:

0.8s - 1.2s

Utilizar cubic-bezier para que el movimiento se sienta natural.

19. ANIMACIONES STAGGER

==================================================

Para grupos de elementos utilizar stagger.

Ejemplo:

Elemento 1 → 0ms

Elemento 2 → 100ms

Elemento 3 → 200ms

Elemento 4 → 300ms

Aplicarlo especialmente a:

- habilidades

- proyectos

- botones

- elementos de contenido
